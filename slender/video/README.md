# Death video

Положи файл сюда:

```
frontend/public/slender/video/death.mp4
```

Последовательность смерти:

1. `death.mp4` (без звука) стартует; `audio/jumpscare.mp3` включается в тот же момент, когда видео реально пошло (`playing`)
2. Когда оба закончились — пауза 1 секунда (чёрный экран)
3. Текст «ТЫ МЁРТВ» + `audio/death.mp3`
4. Рестарт

Клип предзагружается при входе в игру (blob), GIF не нужен — он тяжелее и хуже по таймингу.

Формат: `.mp4` (H.264). Имя файла строго `death.mp4`.
